# AerisVault UI

Thin UI shell for AerisVault simulation post-processing. Orchestrates `dynaprocessing` for data handling and analysis.

## Development Setup

1. Activate monorepo venv:
   ```bash
   source ../../.venv/bin/activate
   ```

2. Install in editable mode:
   ```bash
   pip install -e .
   ```

3. Run the app:
   ```bash
   streamlit run src/aerisvault/app.py
   ```
